01 / The problem

The problem was never notifications.
It was the switching.

The moment you care about more than one account of the same kind — two Messenger logins, a study board and a job feed — your options are to log out and back in, juggle browser profiles, or accept that everything bleeds together.

Bop treats separation as the primary thing to get right. A space is not a tab. It is a full browser session that happens to live inside the same window.

  1. Without Bop Log out. Log back in. Lose the tab. Repeat at 9 a.m.
  2. With Bop Press A, B, C or D. Everyone stays signed in.

02 / Spaces

Four doors.
Different keys.

Cookies, site storage and cache never cross a space boundary. Two Facebook accounts on the same machine genuinely cannot see each other.

Clear one, keep the rest

Clearing a space removes that space's cookies, site storage and cache. Every other account stays signed in.

Hide is not delete

Hide removes a space from the list but keeps its local login and its picture. Delete removes the space and erases its browser profile.

Pages sleep, logins don't

Three pages stay live by default. Others go to sleep, are labelled asleep, and wake when you open them. On 0.2.1 one sleeping page returned about 90 MB.

No fixed ceiling

Spaces are named A…Z, AA… — a naming scheme, not a limit. One AI space is one login; add the same assistant twice for two accounts.

03 / What makes it different

A quiet hub, not another inbox.

Bop is a notification assistant. It shows you that something happened and opens the real conversation. It does not host a chat UI, and it never pretends to.

01

A bubble that knows which account moved

A small round overlay, docked to the screen edge. Set it to 48, 56, 64, 72 or 80 px, choose its transparency, what a double-click does, and whether it floats over full-screen apps. Or use a picture of your own.

The badge counts chats, not messages

04

Turn the phone's notifications into cards

Android

Grant notification access and Bop's own listener turns the phone's notifications into per-account cards and a per-account bubble badge. A web session's unread signals work separately, without notification access.

05

Nothing leaves the device

No Bop server, no Bop account, no telemetry, no crash reporting. Settings are encrypted with the operating system's own key store when one is available. Alerts live in memory and are gone when Bop closes. The one opt-in exception: the Quick notes LAN sync, which you turn on yourself and which moves note text and images between your own phone and your own desktop over your own Wi-Fi, encrypted, and never to the internet.

06

The hub gets out of the way

Closing the hub hides it to the tray, where it keeps listening. Quit is the only thing that stops it. Startup with Windows is one switch, and the page budget is yours: 3, 5, 8 or all.

05 / How it works

Three minutes to a quieter desk.

  1. 01

    Add a space

    Choose a service from the catalog, or on the desktop paste any address. Name it for the account, not the app: Work Facebook, not Facebook.

    Desktop · Android

  2. 02

    Sign in once, per space

    Each space keeps its own cookies and storage. Leave it running in the background pane; switching between Spaces, Alerts, Settings and Guide never closes it.

    Desktop · Android

  3. 03

    Let the bubble tell you

    Close the hub to the tray, or keep the phone bubble docked. When something arrives, the badge moves. Tap the card to open the real conversation in its own session.

    Desktop · Android

  4. 04

    Watch the pages that matter

    On the desktop, add a watch to a task panel with an optional selector and phrase. On the phone, the notification listener covers the apps that post notifications. Neither invents a message.

    Desktop watches · Android notifications

Two apps, two jobs — not a port

Desktop

Parallel logins and task-panel watching. Native tab-title events, tray delivery, an opt-in page check every few minutes.

Android

Installed-app notifications and parallel web logins. WebView title events while a space is loaded, best effort when off-screen.

What Bop does not do

  • It is not a messaging client and does not host a chat UI. It tells you something happened and opens the real conversation.
  • It cannot recover a notification that was never posted. Muted chats, an already-open chat, or a suspended session leave nothing to observe.
  • An unread marker is a count, not a message. A dot cannot say which message is new.
  • Background delivery is best effort on both platforms. Doze suspends timers; Android may kill an off-screen web session.
  • No real signed-in service account has been exercised in this repository's verification. Neither build is code-signed.

08 / Questions

The honest answers.

Does Bop replace Messenger, WhatsApp or Instagram?

No. Bop is a session hub and a notification assistant. It shows you that something happened and opens the real conversation inside that account's own session. Messages are still sent and read in the service's own page or app.

Why does Windows warn me before it runs?

Neither desktop file is code-signed, so SmartScreen shows “Windows protected your PC”. Choose More info → Run anyway, or build and sign it with your own certificate. The Android release APK is unsigned too: sign it before installing or sharing it.

Which versions does it run on?

Windows 10 or 11, x64. Android 7.0 (API 24) or newer to install — a web space needs Android 9 (API 28), so on Android 7–8 you get notification cards and the app catalog only. The desktop app is Electron; the phone app is Kotlin with Compose.

Do I need a Bop account?

No, and there is nowhere to make one. Bop has no server and no analytics. You sign in to each service inside its own space, and those cookies stay in that space's local browser profile.

Does Bop read my messages?

On Android it reads message-like notifications through notification access, keeps previews in memory, and never writes them to disk. Web monitoring uses the WebView tab title, not an injected script or a DOM observer. On the desktop it reads the tab title, and for a space you chose to watch, that page's own text to tell you it changed. No message bodies, senders or credentials are extracted.

Will it keep running when the hub is closed?

On Windows, closing the hub hides it to the tray and it keeps listening; only Quit stops it. On Android, delivery is best effort: Android may suspend an off-screen web session, Doze suspends timers, and some phone brands kill background apps. The app's “Runs on every phone” checks name the settings that matter.

Can two accounts of the same site really stay separate?

Yes — that is the whole design. Each space has its own cookies, site storage and cache, so two Facebook logins never see each other. The repository's integration harness asserts two same-origin sessions on the desktop, and the Android spaces use separate web profiles.

Is Bop free? Can I redistribute it?

It is an independent project with no paid tier and no ads. Careful with redistribution: the repository grants no open-source licence yet, so the source is public but reuse rights are reserved. Ask in the repository before shipping a modified build.
