## Read this before publishing anything

1. **There is no licence.** This matters most for redistribution. `README.md` says "No licence is
   granted by default." Until a licence file exists, uploading the build to itch.io or a store grants
   downloaders no rights — decide the licence first.
2. **Neither artifact is signed.** Windows shows SmartScreen on first run; the release APK is unsigned.
   Say so on every page rather than letting a warning read as a surprise.
3. **No real signed-in account has been exercised.** Do not use words like "battle-tested",
   "production-ready", or "works with your accounts" — the repo's own limits section forbids it.
4. **Pick tags that describe the tool, not a messenger.** Bop is a session-separation utility; it is
   not a chat client. Avoid `Messaging` / `Social` as the primary category.
5. **Only link a download you have.** The portable EXE is built, not committed
   (`desktop/dist/` is ignored). Publish a GitHub Release asset and link that, or link the repo and the
   build instructions.
